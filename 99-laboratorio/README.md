# 99 · Laboratório

O canto dos **experimentos**: rascunhos, provas de conceito e ideias soltas que
ainda não encontraram sua estante. É um espaço deliberadamente bagunçado — mas com
uma regra.

## 📐 A regra

Nada fica aqui para sempre. Quando um experimento amadurece, ele **se muda** para a
estante temática certa e ganha um repositório próprio. O laboratório é passagem, não morada.

## 🧪 O que pode aparecer aqui

- Testes de bibliotecas e ferramentas novas.
- Esboços de projeto antes de definir escopo.
- Ideias de fim de semana.
