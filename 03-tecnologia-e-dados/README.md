# 03 · Tecnologia e dados

Estante da **habilidade transversal** que atravessa todas as outras: a capacidade
de construir software, aplicar IA e trabalhar com dados. É o que me diferencia —
um médico que **constrói as próprias ferramentas**.

Aqui a organização é por **competência técnica**, não por tema médico. Um mesmo
projeto pode aparecer numa estante clínica (pelo assunto) e ser referenciado aqui
(pela técnica que demonstra).

## 📚 Prateleiras

| Prateleira | Foco |
|---|---|
| [`aplicativos-web`](aplicativos-web/) | Apps de página única, GitHub Pages, front-end |
| [`inteligencia-artificial`](inteligencia-artificial/) | IA aplicada à saúde e ao ensino |
| [`ciencia-de-dados`](ciencia-de-dados/) | Análise, visualização e pipelines de dados |

## 🎯 O que pertence aqui

- Padrões e boilerplates reaproveitáveis entre projetos.
- Notas técnicas de arquitetura, deploy e ferramentas.
- Provas de conceito de tecnologia (que depois viram projeto temático).
